# Imágenes

Coloca aquí la foto de ganado/pastizal para el login con el nombre exacto:

```
hero-cattle.jpg
```

(o `.png` / `.webp`, ajustando la extensión en `HERO_IMAGE_URL` dentro de
`src/features/auth/components/login-hero.tsx` y `src/app/(auth)/login/page.tsx`)

Mientras el archivo no exista, se muestra un degradado de reemplazo con la
misma paleta cálida, así que la página nunca se rompe por falta de imagen.

Recomendaciones: orientación horizontal, buena resolución (mínimo 1600px de
ancho), tomada con luz cálida/dorada para que el texto oscuro superpuesto se
siga leyendo bien.
