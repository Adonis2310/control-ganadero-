# Dificultades técnicas — post-mortems

Post-mortem completo por cada bug grande. Formato: **Problema → Síntoma → Causa raíz → Solución → Lección aprendida**. Los patrones rápidos derivados de aquí van resumidos en `memory/dificultades-tecnicas.md`.

_(Aún no hay post-mortems registrados. Se añade uno cada vez que se resuelve un bug importante.)_

## Plantilla

### [Fecha] — Título corto del problema
- **Problema**: qué se intentaba hacer.
- **Síntoma**: qué se observó (error, comportamiento incorrecto).
- **Causa raíz**: por qué ocurrió, a nivel técnico.
- **Solución**: qué se cambió para resolverlo.
- **Lección aprendida**: qué recordar para evitarlo en el futuro (candidato a `memory/dificultades-tecnicas.md` si es un patrón repetible).
